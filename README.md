## About Me

I'm a self-taught front-end developer based in Shiraz, Iran, building full-stack web applications with React, TypeScript, and Next.js. I focus on clean architecture, real database-backed apps, and **shipping to production** — not just tutorials.

I also teach web development and AI tools to **30+ students**, covering HTML, CSS, responsive design, and Figma — taking complete beginners from zero to building their own projects.
